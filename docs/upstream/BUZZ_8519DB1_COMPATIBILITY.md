# Buzz `8519db1` source compatibility: plain helper authentication

This is a source review, not a build, deployed-relay test, pin update, or certification of all upstream changes. The diff leaves `buzz-ws-client` and `buzz-sdk` untouched; the `bridge.rs` and `ingest.rs` changes in this interval are test code. The relevant production changes are in relay configuration and admission.

The helper currently [reads `/info` for `self` only](../../helper/src/catalog.rs), so it does not detect this capability before trying ordinary authentication. Discovery is a compatibility signal, not a way to bypass FI admission. No FI assertion acquisition, key pairing client flow, or lease renewal is implemented here.
