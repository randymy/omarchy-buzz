### Maintainer notes

Messaging preview 0.0.7 for Block's Buzz, independently maintained. Native bar,
panel and normal window; authenticated rooms, recent messages, bounded read-only
thread replies, message composition, exact-key mentions and optional generic
notifications. Requires a separately built/installed Rust helper, user systemd
socket, Linux Secret Service and a configured Buzz community/identity. Please
review as manual setup. Hosted and self-hosted communities are supported through
configuration; signed thread reads require a compatible relay revision.

Agent execution is not included in the installed messaging plugin. Proposed
subscription/ACP integrations are separate, opt-in experimental artifacts with
unresolved upstream and real-account acceptance gates. The plugin is not an
approval authority or a security sandbox. Installation and removal instructions,
compatibility pins, limitations and validation evidence are in the repository.
